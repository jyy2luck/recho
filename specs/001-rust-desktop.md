# 纯 Rust 桌面端验证

用户于 2026-11-20 授权开始重写，仅面向 Windows/macOS；源目录 `../Respable`
作为只读参照。本目录独立构建、运行和存储数据，现阶段不替换原版。

## 第一阶段

- egui/eframe + Glow 原生窗口，直接链接 Rust 引擎；无 Flutter、Dart、WebView。
- 复制参照提交 `762a5902c84f91ec250640c6123c1a5286cd658d` 的引擎以保留代理、
  HTTPS、归档、鉴权、超时和安全限制，不在试验中重新实现协议栈。
- 抓包启停、HTTPS 解密开关、监听端口和 CA 路径、列表 URL/方法筛选、记录选择、
  请求/响应头和正文、文本/Hex、完整文本复制、清空。
- 列表仅传递元数据；双击选中记录后读取请求/响应两个方向，切换记录即释放旧正文；正文和列表虚拟滚动。
- 空闲时不持续重绘。引擎在后台线程运行，命令队列和结果邮箱有界。
- 默认数据为平台用户数据目录下的 recho；默认随机端口避免与参照版冲突。
  `RECHO_DATA_DIR`、`RECHO_PROXY_PORT` 可覆盖，目录必须为绝对路径。
- 不自动配置系统代理、导入证书或修改系统信任。

## 验收

1. Release 原生窗口能显示经真实代理转发的请求、状态、请求/响应头和原样正文。
2. 大于 64 KiB 的正文能滚动到末尾；文本完整复制；二进制显示 Hex，压缩正文解码。
3. 抓包暂停/恢复、切换记录/方向、清空后不重现、关闭释放监听端口和 descriptor。
4. 使用隔离目录、随机端口验证；只记录实际测得的平台内存，不承诺固定 MB 目标。
5. Rust 测试、现有引擎集成测试和原生交互/截图通过；Windows 未实测必须明确标注。

## 暂缓

API 编辑器、规则管理 UI、断点 UI、历史浏览、MCP 配置 UI、系统代理和证书安装 UI、
API 多窗口/多标签、六主题、原版像素级对齐及正式签名安装包不属于第一阶段。
这些已有引擎能力不能据此宣称完成桌面迁移。中文界面与嵌入式中文字体；复杂输入法体验另验收。

## 风险

Glow 使用 OpenGL；macOS 已将 OpenGL 标为弃用，Windows 驱动兼容性待真机验证。
如原生功能或驱动验证失败，再评估其他 Rust UI 后端。完整引擎仍有自身有界预览、
SQLite 和 TLS 开销，第一阶段的测量不代表所有功能迁移后的最终体积或内存。
