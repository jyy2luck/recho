## 原生验收

- 抓包工作台支持九列表格、列宽与排序、快捷及条件筛选、自动高亮、多选和右侧请求/响应详情。上下键跨越视口时自动滚动，详情跟随选中行。
- 隔离 macOS Release 冒烟通过了 HTTP 抓包、80,342 字节纯文本和 gzip 解码后的完整复制、81,930 字节二进制 Hex 滚动、启停、清空保留历史、200 条负载、多会话切换、F4 历史和退出释放端口。HAR 的二进制往返和错误输入回滚由 Rust 测试覆盖。
- API 编辑器在原生窗口验证了本地 HTTP 发送、JSON Tree、集合与环境保存，以及关闭窗口后重启恢复草稿和响应。协议夹具验证了原始 HTTP 取消释放连接、WebSocket 经本地代理收发文本及二进制、保存和重开 Protobuf、gRPC 一元和双向流，以及响应元数据、尾部与状态。
- 调试工具在原生窗口验证了规则保存、请求与响应断点编辑、反向代理配置启用、书签快照查看、MCP 令牌创建和撤销、复制连接配置和 Stdio 握手。
- macOS 原生菜单验证了快捷键、启停、主题切换及重启、证书状态检查和取消信任确认。系统代理的原值比较、恢复、偏好保存和无效配置回滚在隔离设置与模拟系统状态中测试。
- `./scripts/check.sh` 通过 15 项桌面 Rust 测试、70 项引擎 Rust 测试、67 项 Node 集成测试。Release 构建和 ad-hoc 签名通过。

## 范围和差异

界面沿用 Respable 的工作台、调试标签、九列表格以及请求/响应分区结构。原生控件由 egui 绘制，支持六套主题。
抓包会话最多显示最近 200 条，历史可独立翻页。HAR 每次最多 200 条、32 MiB。条件筛选的正文和控制台匹配使用抓包预览。
超大断点正文可保留或整体替换，内嵌编辑限 256 KiB。cURL 覆盖常用选项，二进制可在 API 编辑器中保留。WSS 默认验证服务端证书。
Windows 系统代理提供 HTTP/HTTPS，SOCKS5 系统代理接入仅在 macOS 提供。
Windows 界面、高 DPI、中文输入法和真实系统代理/证书变更仍待实机验证。安装包尚未正式签名或公证。
